# matsim-code-examples
A repository containing code examples around MATSim.

The default branch is `dev.x`. This branch is continuously updated with the latest MATSim development version.

If you are interested in the code examples of the latest release version of MATSim, check out the `<version-number>` (e.g. `2025.0`) branch.
